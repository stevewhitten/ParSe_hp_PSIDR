# ParSe_hp_PSIDR
ParSe v2 plus a high-pathogenicity PS-IDR scan. Usage instructions are in the header of each file. The browser-based HTML implementation runs in any modern browser. No server or extra libraries needed.

The one-sequence HTML implementation can be used at stevewhitten.github.io/ParSe_hp_PSIDR/

A multi-sequence FASTA screen can be used at stevewhitten.github.io/ParSe_hp_PSIDR/FASTA/

Please cite Ibrahim et al., J. Biol. Chem. 299, 102801 (2023), and Remo et al. (https://doi.org/10.64898/2026.09.25.754449; citation to be updated on publication).
