# ParSe_hp_PSIDR
ParSe v2 plus a high-pathogenicity PS-IDR scan. Usage instructions are in the header of each file. The browser-based HTML implementation runs in any modern browser. No server or extra libraries needed.

The HTML implementation can be used at stevewhitten.github.io/ParSe_hp_PSIDR/

Please cite Ibrahim et al., J. Biol. Chem. 299, 102801 (2023), and Remo et al. (citation to be updated on publication).
